Build this folder’s POS Windows .exe from PowerShell (use Set-Location to this directory first):

python -m pip install --upgrade pyinstaller certifi
python -m PyInstaller --noconfirm HosnyPOS.spec

Output: dist\HosnyPOS.exe

Copy both files to the cashier PC:

dist\HosnyPOS.exe
dist\cacert.pem

Windows 7 64-bit build:

Install Python 3.7.3 Windows x64, then run:

build_pos_win7_x64.bat

This uses HosnyPOS-win7-x64.spec and pinned dependencies from requirements-win7-x64.txt.
Copy both dist\HosnyPOS.exe and dist\cacert.pem to the cashier PC.

Legacy one-file command (still works):

pyinstaller --onefile HosnyPOS.py --name HosnyPOS
